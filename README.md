# Neural Network From Scratch

A neural network framework implemented from scratch using Python and NumPy.

## Features

- Fully Connected Layers
- Convolutional Layers
- ReLU and Softmax
- Dropout and Flatten
- Forward and Backward Propagation
- Gradient-Based Optimization

## Installation

Clone the repository and navigate into the project directory.

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Running Tests

Execute all tests from the repository root:

```powershell
python -m pytest
```

The test configuration automatically resolves the required Python import paths.

## Project Purpose

This project was developed to gain a deeper understanding of neural network architectures, numerical computation, and backpropagation without relying on high-level deep learning frameworks.
